# Recursion

Nine recursion practice questions covering powers, factorials, array products, range sums, Fibonacci numbers, and backtracking.

Start with [Problems.md](./Problems.md), continue with [MediumProblems.md](./MediumProblems.md), then implement the matching TypeScript starter functions. Each starter deliberately throws until completed.

For every exercise, identify the base case and recursive step, then explain time and call-stack space complexity. Check the examples and boundary cases in Problems.md. Keep inputs and outputs within JavaScript’s safe integer range, and start with small inputs when tracing recursion.

## Extra recursion practice

Continue with [Extra Recursion Problems](./extra%20recursion%20problems/Problems.md): nine additional exercises covering strings, arrays, callbacks and nested objects. Implement the matching TypeScript starter files; no solutions are included.
