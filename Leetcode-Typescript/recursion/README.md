# Recursion

Seven recursion practice questions: all five coding exercises from Udemy Section 8, plus LeetCode Power of Two (#231) and Power of Three (#326).

Start with [Problems.md](./Problems.md), then implement the matching TypeScript starter functions. Each starter deliberately throws until completed.

For every exercise, identify the base case and recursive step, then explain time and call-stack space complexity. Check the examples and boundary cases in Problems.md. Keep inputs and outputs within JavaScript’s safe integer range, and start with small inputs when tracing recursion.
