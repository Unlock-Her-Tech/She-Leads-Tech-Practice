# Setup

1. Clone and open this repository in Visual Studio Code on your computer.
1. If a recommendation appears to install a Node testing extension, accept this. If not, you'll need to open the Visual Studio code extensions tab in the left sidebar (looks like a 2x2 grid with the top-right square at an angle) and install an extension called **node:test runner** by Connor Peet manually.
1. Make sure you have Node installed on your computer (version 24 or higher). If you want to check if you already have it, or if you installed it correctly, try running `node --version` in your terminal.
1. Navigate into this directory (`Leetcode-Typescript/3-Array-Lists-and-Linked-Lists`) and run `npm i`.
1. Open the Visual Studio Code testing tab in the left sidebar (looks like a conical flask) and you should hopefully see a bunch of tests you can run. Try pressing the play button and some should go green (the ones we covered in the session) while the rest should go read.
1. Try implementing each of the functions in the `ListFunctions` directory in turn, checking which tests flip from red to green as you go.

Any issues, give us a shout!
